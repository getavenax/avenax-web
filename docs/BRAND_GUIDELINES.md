# AVENAX — Brand Guidelines

> The brand is protected above everything else (Non-Negotiable Rule #8).
> Visual specification lives in `DESIGN_SYSTEM.md`; this document defines what the brand *is* and how it speaks.

---

## 1. Core Identity

| | |
|---|---|
| **Name** | AVENAX — always uppercase in display contexts; "Avenax" acceptable in running prose only when uppercase would be typographically loud |
| **Domain** | getavenax.com |
| **Slogan** | **Next Standard.** — always with the period; never translated; never modified ("The Next Standard", "Next Standards" are wrong) |
| **Meaning** | We are not building the next version. We are building the next standard. |

## 2. Brand Values

Minimal. Luxury. Elegant. Fast. Innovative. Premium. Future.
Benchmarks: Apple-level quality, OpenAI-level simplicity.
Design inspirations (reference set, not templates to copy): Apple, OpenAI, Linear, Stripe, Vercel, Anthropic, Framer, Arc Browser.

## 3. Brand Philosophy (from the Manifesto)

- AI should work. Automation should feel invisible. Design should be effortless. Products should be beautiful.
- Performance matters. Speed matters. **Execution matters more.**
- Consistency creates trust. Trust creates brands. Brands change industries.

## 4. Design Principles

Minimal. Premium. Modern. Timeless. Functional.
No unnecessary elements. **Every pixel must have a purpose.**

Visual language (specified in `DESIGN_SYSTEM.md`):
- Black & white — the brand surface is 100% monochrome; hierarchy through lightness and typographic weight, never decorative color.
- Large typography; elegant spacing; soft gradients only where purposeful; smooth, restrained motion; premium micro-interactions; no visual clutter.
- Dark-first. The dark surface *is* the brand; light mode is a theme.
- Signature motif: **The Baseline** — a 1px self-drawing hairline, the visual form of "a standard." The one place boldness is spent; everything around it stays quiet.

## 5. Voice & Tone

- **Short sentences. High confidence. Zero hype.** The manifesto's cadence is the brand voice.
- Educate, demonstrate, prove — never sell with adjectives. Specific beats clever.
- Plain verbs, sentence case in UI, active voice. A button says exactly what it does.
- We say what we build and what we refuse to build. Restraint is part of the voice.
- Never: exclamation-mark enthusiasm, buzzword chains ("revolutionary AI-powered synergy"), fake urgency, engagement bait.

## 6. Product Positioning Language — AVENAX Insight

Permanent, legally significant wording rules (see `DECISIONS.md` ADR-004):

**Always:** educational analysis · decision support · market understanding · learn · understand · scenario · probability · risk education.
**Never:** buy/sell recommendations · signals · guaranteed · profit promises · "you should enter/exit" · investment advice.

Every marketing surface and every product response reinforces the educational positioning. This is architecture, not a footnote.

## 7. Content Strategy

Content is not marketing. Content is education, proof, and trust.
Formats (when Media pillar activates): YouTube, AI experiments, automation, product development, educational content, AI stories, AI animation, autonomous content systems.
Rules: content must always increase brand value; never create content only for views; media properties are growth engines and independent assets for the entire ecosystem (ads, sponsorship, partnerships, product user acquisition).
Current mode: minimal — document the build journey only, until first paying customer.

## 8. The AVENAX Standard (every product, every surface)

Simple. Fast. Reliable. Beautiful. Scalable. Human-centered. Intelligent. Global.

## 9. What the Brand Never Does

- Chase trends or attention. (We build products. We build trust.)
- Ship features nobody needs or software that wastes attention.
- Overcomplicate experiences.
- Sacrifice quality for speed, or user trust for short-term growth.
- Build for today. (We build for the next decade.)

## 10. Brand Protection Checklist

Before anything public ships, verify:
1. Does it look and read like AVENAX (monochrome, minimal, confident, calm)?
2. Would we be proud of it if AVENAX is a global company in ten years? (The Founder Rule)
3. Does it use only design-system tokens and approved voice patterns?
4. If it touches Insight: is the educational positioning intact?
5. Does it increase brand value — not just views, clicks, or noise?
